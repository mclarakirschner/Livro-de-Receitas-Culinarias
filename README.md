## 📌 Descrição do Projeto
Este projeto é um sistema web para cadastro e gerenciamento de **receitas culinárias**, desenvolvido como atividade prática da disciplina de Desenvolvimento Web.

O sistema permite:

- Cadastro de usuário e login com Supabase Auth  
- Cadastro de receitas com título, ingredientes, categoria e data  
- Cadastro e listagem de categorias  
- Cada usuário só vê suas próprias receitas  
- Segurança com RLS (Row Level Security)  
- Interface responsiva usando TailwindCSS
